# UFO Dog — инопланетный скин маскота

Самостоятельная модель собачки: свои SVG, своя структура слоёв, свои данные морфинга и свой
движок отрисовки. Поведение (12-секундная последовательность, тайминг, амплитуды, движения
частей тела) общее с Original Dog и Skeleton Dog: настройки поведения и траектории частей
тела берутся из оригинального компонента только для чтения.

## Состав

```text
variants/ufo/
├── assets/                  ufo-pose-1.svg, ufo-pose-2.svg (исходники)
├── animations/
│   ├── ufoAnimation.js      движок скина (createUFOAnimation), физика усиков
│   ├── ufoMorph.js          морфинг контуров и градиентов, изгиб усиков
│   └── ufoMorphData.json
├── components/UFODog.jsx
├── tools/build_ufo_data.py
├── demo/                    сравнение Original и UFO на общем таймере
└── index.js
```

## Использование

```jsx
import { UFODog } from './mascot/variants/ufo/index.js';
<UFODog size={240} />
```

Пропсы и методы те же, что у `DogMascot` и `SkeletonDog`. Через реестр:
`SKINS.ufo` в `mascot/variants/index.js`.

Сравнение: `cd mascot && npm run dev`, затем `http://localhost:5173/variants/ufo/demo/`.

## Усики

Каждый усик — часть головы с точкой крепления в основании стебля. Основание движется только
вместе с головой. Стебель изгибается дугой, сильнее к кончику, и шарик поворачивается вместе
с кончиком.

Угол усика складывается из трёх частей:

1. **Покачивание**: медленное, одно колебание за 3-секундный блок; у правого усика
   со сдвигом фазы.
2. **Дыхание**: на вдохе усики чуть расходятся наружу.
3. **Инерция**: отклик затухающей пружины (2,4 Гц, затухание 0,2) на угловое ускорение
   головы и ускорение основания усика. Поэтому при повороте головы усики отстают, при
   приседании и возвращении качаются сильнее и затухают за несколько колебаний.
   Размах мягко ограничен 12°.

Отклик считается только по времени последовательности, без накопленного состояния.
Поэтому движение одинаковое при воспроизведении, перемотке, замедлении и на стыке повторов.
Все параметры — в `ANTENNA_CONFIG` (`animations/ufoAnimation.js`).

## Размеры

В середине приседания и возвращения шарики усиков поднимаются примерно на 11 единиц выше
верхнего края поля 240×240. Компонент рисует их за пределами своей рамки
(`overflow: visible`), поэтому над ним в макете нужен небольшой запас места. Для экспорта
в TGS (512×512) композицию нужно будет немного уменьшить или опустить.

## TGS

Колебания усиков после возвращения продолжаются в начале следующего блока первой позы.
Поэтому первый блок после игровой позы отличается от двух следующих, и при экспорте
в TGS для него понадобится отдельный вариант блока.

## Пересборка данных

```bash
python3 mascot/variants/ufo/tools/build_ufo_data.py
```
