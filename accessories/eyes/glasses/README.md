# glasses — очки

Аксессуар для глаз собачки Telegram Mascot. Отдельный компонент: собачка (`mascot/`) не меняется,
очки надеваются на неё снаружи и снимаются без следа.

## Подключение

```tsx
import { DogMascot } from '<путь>/mascot/index.js';
import { Glasses } from '<путь>/accessories/eyes/glasses';

<Glasses>
  <DogMascot size={240} />
</Glasses>

<Glasses enabled={false}>…</Glasses>   // очки сняты — обычная собачка
<Glasses motion={false}>…</Glasses>    // без блеска и пошатывания, только посадка
```

С другими аксессуарами: `<Duck><Glasses><Ball><DogMascot /></Ball></Glasses></Duck>`. Свои `ref`
и `onFrame` на `DogMascot` продолжают работать.

| Свойство | Тип | По умолчанию | |
|---|---|---|---|
| `children` | `<DogMascot />` | — | собачка, на которую надеваются очки |
| `enabled` | `boolean` | `true` | надеты ли очки |
| `motion` | `boolean` | `true` | блеск линз и пошатывание при смене позы |
| `className`, `style` | | | для обёртки (`<span>`, inline-block) |

Без React — к собачке из `createDogAnimation`:

```js
import { createDogAnimation } from '<путь>/mascot/index.js';
import { createGlasses } from '<путь>/accessories/eyes/glasses';

let glasses = null;
const dog = createDogAnimation(svg, { autoPlay: false, onFrame: info => glasses && glasses.update(info) });
glasses = createGlasses(svg);
dog.play();

glasses.setVisible(false);   // спрятать
glasses.destroy();           // снять
```

SVG подключается как текст (`glasses.svg?raw`) — это работает в Vite; в других сборщиках нужен
аналогичный загрузчик «файл как строка».

## Посадка

В DOM очки — отдельная группа `<g data-accessory="glasses">` в конце группы головы собачки
(`data-part="head-rig"`), поверх головы и ушек. Поворот головы и подъём при дыхании они получают
тем же преобразованием, что и голова, а смену позы повторяют по тем же данным риггинга и с той же
плавностью — не скользят и не отстают ни на кадр.

Расположение измерено по двум референсам (`accessories/tools/fit_placement.py … glasses`). Глаза
собачки на референсах закрыты линзами, поэтому скриншоты совмещаются с собачкой по её серому
контуру и носу (точность — в пределах 0,2 единицы, проверено на референсах других аксессуаров).

| Поза | x | y | наклон | масштаб |
|---|---|---|---|---|
| 1 | 47,87 | 49,01 | −0,02° | 1 |
| 2 | 44,52 | 75,27 | 15,13° | 1 |

## Свои движения

Поверх привязки к голове; посадка при этом не меняется. Настройки — `GLASSES_MOTION`
в `glassesMotion.js`.

| Движение | Как устроено |
|---|---|
| Блеск линз | Быстрая светлая полоса — две параллельные полоски в светлом тоне (`STREAK` в `glassesMotion.js`) — проходит по стеклу слева направо: появляется, скользит, по пути немного расширяется и исчезает (0,5 с на линзу, яркость до 55 %). Сначала по левой линзе, через 0,09 с — по правой. Полоса обрезана по форме линзы и лежит под оправой, поэтому не выходит за стекло. Повторяется в каждом 3-секундном блоке в один и тот же момент (1,4 с от начала блока), между проходами — пауза. Блики, оправа и линзы из SVG не меняются. |
| Пошатывание при смене позы | Очки слегка поворачиваются вокруг переносицы — пружина, которую раскачивает ускорение головы. При приседании и вставании — около 3–4°, затем несколько плавных затухающих колебаний (около секунды) и возврат на место. Очки не спадают и не отрываются. |

Пошатывание начинается вместе с движением головы и никогда его не опережает. После вставания оно
продолжается в начале следующего цикла и затихает примерно за секунду. Все движения рассчитаны по
времени последовательности: перемотка, пауза и любой кадр всегда показывают одно и то же.

## Совместимость с TGS

Посадка — смещение, поворот и масштаб группы; пошатывание — поворот ещё одной группы; блеск —
смещение, масштаб и прозрачность полос внутри маски по форме линзы (в Lottie — Alpha Matte).
SVG-файл не меняется. Тень очков в SVG сделана размытием (`feGaussianBlur`): в Lottie/TGS это
эффект Gaussian Blur, его стоит проверить при экспорте. Первый блок позы 1 с очками — отдельный
файл (в нём затихает пошатывание после вставания), второй и третий — одинаковые.
