# bone — косточка во рту

Аксессуар для рта собачки Telegram Mascot. Отдельный компонент: собачка (`mascot/`) не меняется,
косточка надевается на неё снаружи и убирается без следа.

## Подключение

```tsx
import { DogMascot } from '<путь>/mascot/index.js';
import { Bone } from '<путь>/accessories/mouth/bone';

<Bone>
  <DogMascot size={240} />
</Bone>

<Bone enabled={false}>…</Bone>   // косточка убрана — обычная собачка
<Bone motion={false}>…</Bone>    // без своих движений, только посадка во рту
```

С аксессуаром на голову: `<Bow><Bone><DogMascot /></Bone></Bow>`. Свои `ref` и `onFrame` на
`DogMascot` продолжают работать.

| Свойство | Тип | По умолчанию | |
|---|---|---|---|
| `children` | `<DogMascot />` | — | собачка, которая держит косточку |
| `enabled` | `boolean` | `true` | показана ли косточка |
| `motion` | `boolean` | `true` | дыхание и покачивание при смене позы |
| `className`, `style` | | | для обёртки (`<span>`, inline-block) |

Без React — к собачке из `createDogAnimation`:

```js
import { createDogAnimation } from '<путь>/mascot/index.js';
import { createBone } from '<путь>/accessories/mouth/bone';

let bone = null;
const dog = createDogAnimation(svg, { autoPlay: false, onFrame: info => bone && bone.update(info) });
bone = createBone(svg);
dog.play();

bone.setVisible(false);   // спрятать
bone.destroy();           // убрать
```

SVG подключается как текст (`bone.svg?raw`) — это работает в Vite; в других сборщиках нужен
аналогичный загрузчик «файл как строка».

## Посадка

В DOM косточка — отдельная группа `<g data-accessory="bone">`, первая внутри группы головы собачки
(`data-part="head-rig"`). Голова и ушки рисуются поверх: край мордочки перекрывает середину
косточки, как будто собачка держит её во рту; концы лежат поверх тела и лап. Поворот головы и подъём
при дыхании она получает тем же преобразованием, что и голова, а смену позы повторяет по тем же
данным риггинга и с той же плавностью — не скользит и не отстаёт ни на кадр.

Расположение измерено по двум референсам (`accessories/tools/fit_placement.py … bone`):

| Поза | x | y | наклон | масштаб |
|---|---|---|---|---|
| 1 | 49,12 | 128,08 | −0,04° | 1 |
| 2 | 25,17 | 143,66 | 18,96° | 1 |

## Свои движения

Поверх привязки к голове; посадка во рту при этом не меняется. Вся косточка двигается как одно
целое (одно преобразование группы), форма не искажается. Настройки — `BONE_MOTION` в `boneMotion.js`.

| Движение | Как устроено |
|---|---|
| Дыхание | Косточка равномерно увеличивается до 2 % по той же кривой и в той же фазе, что дыхание собачки. |
| Покачивание при смене позы | Косточка слегка наклоняется вокруг середины стержня, где её держит рот, — пружина, которую раскачивает ускорение головы. При приседании и вставании — около 3,5–4°, затем несколько плавных затухающих колебаний (около 1,5 с) и возврат на место. Точка во рту остаётся на месте — косточка не выпадает и не смещается. |

Покачивание начинается вместе с движением головы и никогда его не опережает. После вставания оно
продолжается в начале следующего цикла и затихает примерно за полторы секунды. Все движения
рассчитаны по времени последовательности: перемотка, пауза и любой кадр всегда показывают одно
и то же.

## Совместимость с TGS

Посадка — смещение, поворот и масштаб группы; свои движения — поворот и масштаб ещё одной группы
вокруг косточки. SVG-файл не меняется. В Lottie/TGS это отдельный слой с родителем «голова», ниже
слоёв головы и ушей. Первый блок позы 1 с косточкой — отдельный файл (в нём затихает покачивание
после вставания), второй и третий — одинаковые.
